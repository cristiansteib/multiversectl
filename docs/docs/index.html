The shape of it

One file says which repositories your system is made of and how to run them. A universe is one copy of all of it: each repository's compose files started as a compose project of their own, each with its own network. That is where the isolation comes from — two universes share no network, so nothing in one can reach the other's services.

Nothing publishes a host port, because two copies of one stack cannot both have port 8000. One proxy holds one set of ports for the machine and tells universes apart by the hostname in the request, so the tenth universe costs no ports and changes no configuration anywhere. Your own compose files are not edited: the proxy labels, the dropped ports and each universe's own values go into a generated file beside your checkouts.
