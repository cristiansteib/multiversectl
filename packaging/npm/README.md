# multiversectl

Run several complete copies — **universes** — of a multi-repository project on
one machine, each with its own branch, containers and hostnames.

multiversectl is a single Go binary. This package exists so the name on npm
belongs to the project; it does not install the tool. Use one of:

```sh
curl -fsSL https://multiversectl.dev/install.sh | sh
brew install cristiansteib/tap/multiversectl
mise use -g ubi:cristiansteib/multiversectl
```
