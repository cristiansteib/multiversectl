multiversectl

Run your whole multi-repository system several times at once, on one machine. Each run gets its own branch, its own containers, its own data and its own hostnames — so several people, or several agents, can work different branches at the same time without taking turns.

Install Docs GitHub

Apache 2.0. One binary for Linux and macOS, no daemon of its own.

two universes, one machine
